# Contributing to OpenShift Secure Architecture Blueprint

## Types of Contributions

- Security hardening YAML manifests
- Compliance mapping additions (PCI DSS, NIST, CIS, SOC 2)
- Monitoring and alerting rules
- Documentation improvements
- GUI enhancements
- Threat model updates

## Standards

- All YAML must be valid and include comments explaining security rationale
- Reference the applicable CIS/NIST/PCI control ID in comments
- Test manifests against OpenShift 4.14+ before submitting
- Follow existing naming conventions and directory structure

## Submission

1. Fork the repository
2. Create a feature branch
3. Submit a pull request with a clear description of changes and applicable control IDs
